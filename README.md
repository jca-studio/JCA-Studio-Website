## Deploy
1. Back up the existing repository or create a branch.
2. Copy all files and directories in this folder into the repository root (replace the old index.html).
3. Commit to a non-production branch for Vercel Preview; verify on desktop and mobile.
4. When approved, merge into the production branch.
5. Confirm the desired public domain and lift Vercel Authentication only when ready.
